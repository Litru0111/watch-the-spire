## 快速定位

**「界面上的数字不对」** → 先看 [数据来源.md](数据来源.md)，
确认那个字段出自哪个文件、有没有已知延迟。

**「某个测试跑不过 / 跳过了」** → [测试说明.md](测试说明.md) 里有分层表，
第三档需要真实存档。

**「为什么这里要这么写」** → [历史笔记.md](历史笔记.md) 按主题记录了原因，
多数条目都写明了「早先怎么写错的」。

**「环境/路径找不到」** → 跑 `sts2mon.cmd doctor`，
它会打印路径解析结果与来源（环境变量 / 自动探测 / 默认值）。
